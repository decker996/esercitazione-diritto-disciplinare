# Diritto Disciplinare – esercitazione

Sito statico (GitHub Pages) per esercitarsi sui quesiti a risposta multipla di Diritto Disciplinare militare
(8° Corso Applicativo). `index.html` è il manuale d'uso, `esercitazione.html` l'esercitazione; i quesiti sono in
`banca_dati.json`, generato dalla banca sorgente con `quiz.py pubblica` (non si modifica a mano).

Raccolta personale, senza carattere ufficiale. Errori: aprire una segnalazione (Issues) con il codice del quesito.
